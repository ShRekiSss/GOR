# Changelog

## 1.0.2 — 2026-10-26

Профили, Web Push и админ-панель.

### Клиент

- **Профиль**: своя карточка (display name, bio, status), чужая карточка с
  «Написать»/«Позвонить», публичная ссылка `/u/:username`, раздел «Друзья»
  по личным диалогам.
- **Web Push**: подписка VAPID, обработчики в service worker, тумблер в
  настройках; уведомления приходят, когда приложение закрыто.
- **Поиск по чату**, черновики и пересылка сообщений.
- Мем-кнопки в композере; подсказки на панели стикеров.
- Кнопки без связи объясняют, почему недоступны; Enter на телефоне не
  отправляет сообщение.

### Сервер

- `GET/PATCH /api/me/profile`, `GET /api/users/{u}/profile`,
  `GET /api/me/friends`.
- **Web Push VAPID** (ES256 + RFC 8291 aes128gcm): ключи и подписки в D1,
  маршруты `/api/push/*`, отправка офлайн-участникам из Durable Object.
- **Админ-панель**: `is_admin`/`banned`, `/api/admin/users`, бан гасит
  REST/WS/сессии/пуши и закрывает вход, переименование пользователей.
- **WS-изоляция чатов**: broadcast только участникам (кэш состава, TTL 60 с,
  fail-closed) — чужой не читает, не пишет и не реагирует в чужом чате.
- `/api/giphy` — прокси с кэшем и лимитом, ключ остаётся на сервере.

### CI

- APK подписывается настоящим релизным ключом — обновление ставится поверх
  предыдущей установки.
- Исправлена потеря `ANDROID_*_HOME` при вызове gradle, сборка universal APK
  на 4 ABI стабильна.

## 0.9.1 — 2026-10-22

Упор на Android-клиент: надёжность в фоне, живая история, PWA-обновления и
автосборка APK в CI.

### Сервер

- **Время сообщений** теперь ISO UTC (`2026-10-22T09:41:00Z`): у сообщений
  снова есть дата и часовой пояс (раньше писалось только `ЧЧ:ММ:СС`).
- **Присутствие — события, а не сообщения**: `/hub` рассылает
  `{"type":"presence","event":"join|leave","username":…,"online":…}` всем
  клиентам. Больше не пишется «[x] присоединился к чату» в общий чат —
  ни спама, ни утечки входов в историю.
- **Пагинация истории**: `GET /api/chats/{id}/messages` принимает
  `?after=<id>` (догон после разрыва связи, по возрастанию),
  `?before=<id>` (страница старых сообщений) и `?limit=` (≤300).
  Ответ: `{"messages":[…],"hasMore":bool}`.
- **Доверенные прокси**: `GOR_TRUSTED_PROXIES` (IP/CIDR, по умолчанию
  loopback) — `X-Real-IP`/`X-Forwarded-For` учитываются только от них,
  rate-limit по-честному защищён от подделки заголовков при прямом доступе.
- **GIPHY через сервер**: `GET /api/giphy?q=` — ключ держим в
  `GOR_GIPHY_KEY` на сервере (в бандле его больше нет), rate-limit 120/мин.
- Пограничный баг пагинации: аргументы запроса истории не совпадали
  с плейсхолдерами (пустая история при переваливании 100 сообщений).

### Клиент (Android/PWA/desktop/web)

- **WS-реконнект с backoff** (0.5s → 10s): приложение в фоновом режиме
  больше не теряет сообщения — после восстановления связи подтягивается всё
  пропущенное (`?after=…`) и обновляется список чатов.
- **Прогулка по истории вверх**: подгрузка старых сообщений при скролле
  за верх, экран не «прыгает» после вставки.
- **Разделители дней** («Сегодня» / «Вчера» / дата) и локальное время у
  каждой старой записи — история читается как в мессенджере.
- **Индикация онлайна** теперь считается по WS-событиям presence (опрос
  `/api/stats` остался как запасной на случай разрыва).
- Поиск GIF ходит в `/api/giphy` своего сервера.

### PWA (Android/PWA)

- **Приложение наконец обновляется**: shell (`index.html`) теперь
  network-first, кэш v2 — новые бандлы подхватываются без «Очистить данные».
- `theme-color` выверен с манифестом/фоном (`#0e1621`), apple-title — VAKSA.

### Сборки и CI

- **CI собирает APK** (`android` job: NDK + 4 ABI) и публикует его в релиз.
  Если заданы секреты `ANDROID_KEYSTORE_BASE64/PASSWORD/ALIAS` — релизная
  подпись, иначе debug-APK (ставится «из неизвестных источников»).
- `desktop/patch-android-permissions.sh`: в AndroidManifest автоматически
  добавляются `RECORD_AUDIO`, `MODIFY_AUDIO_SETTINGS`, `POST_NOTIFICATIONS`,
  `FOREGROUND_SERVICE`, `VIBRATE` — фундамент под голосовые звонки.
- Версии бандлов: 0.9.1.

## 0.9.0-beta — 2026-10-21

Этап безопасности (без домена, но уже защищённо).

### Сервер

- `/uploads/*` и `/api/download` больше не открыты всем: доступ только
  по токену (Bearer, cookie или `?t=`) и только участникам чата, к которому
  прикреплён файл (`chat_id` ищется по сообщению).
- WebSocket: токен больше не в URL — клиент авторизуется **первым кадром**
  (`{"type":"auth","token":...}`), сервер шлёт `auth_ok` / `auth_error`.
  Токен больше не попадает в логи прокси.
- Rate-limit на `/api/auth/*` уже был — подтверждён тестом (20 попыток → 429).
- Авто-бэкап: `deploy/gor-backup.sh` + systemd timer `gor-backup.timer`
  (ежедневно 03:30, снапшот SQLite VACUUM INTO, инкремент uploads, хранить 7).

### Клиент

- `serverWsUrl()` без токена в URL; токен отправляется первым WS-кадром.
- Ссылки на файлы автоматически получают `?t=<token>` (`resolveUrl`).

### Linux = Windows

- Единый вид на всех десктопах: те же иконки (губка), та же тёмная тема,
  `.deb`/AppImage собираются из одного `tauri.conf.json`; в bundle добавлен
  `icons/icon.png` (512) для иконки окна/меню приложений.

## 0.7.0-beta — 2026-10-21

Мобильная итерация: жестовое управление Android-клиента в стиле
Signal-Android (паттерны open-source проектов Signal и Revolt).

### Android / PWA — жесты

- Двухэкранная навигация: список чатов ↔ переписка отдельными экранами
  (полноэкранно, выезд анимацией, как в Signal).
- Свайп вправо от левого края = «назад» к списку; быстрый флик тоже закрывает.
- Системная кнопка «назад» (Android) закрывает верхний слой: чат → нижний
  лист → модалка — через History API, ничего не «зависает».
- Долгое нажатие на чат → нижний лист с инфо и быстрым открытием.
- Долгое нажатие на сообщение → копирование в буфер + toast.
- Pull-to-refresh в списке чатов (индикатор-спиннер).
- FAB «＋» для нового чата → нижний лист: личный чат / группа.
- Настройки и модалки на мобильном открываются как нижние листы (bottom sheet).
- «Зубчатые» safe-area отступы (вырез/жест-бар), 100dvh высота,
  interactive-widget=resizes-content — клавиатура не ломает раскладку.

### Сборки

- Версия бандлов: `0.7.0` (APK versionCode `7000`, апгрейд поверх 0.5.0 работает).
- APK пересобран (universal, 4 ABI) и подписан тем же ключом
  `gor-release.jks` — обновление устанавливается без удаления.

## 0.5.0-beta — 2026-10-20

Первая бета с полноценными чатами и desktop-интеграцией.

### Сервер

- Личные диалоги 1-1 и группы, список чатов, непрочитанные.
- API: `/api/chats`, `/api/chats/{id}/messages`, `/api/chats/{id}/read`,
  `/api/users?q=`.
- WebSocket доставляет сообщение только участникам чата; запись в чужой чат
  блокируется.
- Загрузка файлов привязана к чату и проверяет членство (`chatId`).
- Миграция существующей базы: общий чат, `chat_id`/`user_id` у старых сообщений,
  все аккаунты автоматически добавлены в «Общий чат».
- Версия сервера: `0.5.0-beta`.

### Клиент

- Сайдбар со списком чатов, последним сообщением, временем и бейджем
  непрочитанных.
- Создание личного чата поиском пользователя и группы с несколькими участниками.
- Адаптивная мобильная вёрстка: off-canvas сайдбар, кнопка ☰, компактный ввод.
- Браузерные уведомления о новых сообщениях (когда окно не в фокусе).
- «Общий чат» открывается по умолчанию, непрочитанные не теряются при входе.

### Desktop (Tauri 2)

- Иконка в системном трее: «Открыть GOR» / «Выход»; закрытие окна прячет
  приложение в трей.
- Автозапуск при входе в систему (галочка в настройках).
- Нативные системные уведомления через `tauri-plugin-notification`.
- Windows: portable `.exe` и NSIS-установщик `GOR_0.5.0-beta_x64-setup.exe`.
- Linux: `.deb` (AppImage — при наличии корректного pkg-config).

### Android

- PWA: manifest, service worker, иконки — сайт ставится как приложение.
- APK через Tauri 2 (universal, 4 ABI), подписанный локальным ключом.

### Известные ограничения

- Нет сквозного шифрования; сервер хранит сообщения в открытом виде в SQLite.
- Файлы в `/uploads/` доступны по прямой ссылке.
- Установщики Windows не подписаны (SmartScreen → «Подробнее» → «Выполнить всё равно»).
- Публичный тестовый туннель localhost.run меняет адрес после переподключения.
