# VAKSA 🧽 (бывший GOR)

Тёмный мессенджер — типа Telegram, только свой и без зависимости от кого-либо.
Писать можно с Windows, Linux, Android. Один бинарник — один сервер — сколько угодно людей.

---

## 📲 Хочу поставить себе — **жми сюда 👉 [Releases](https://github.com/ShRekiSss/GOR/releases/latest)**

Там лежат готовые файлы, качай под своё:

| Ты с телефона 📱 | Ты на винде 🪟 | Ты на линуксе 🐧 |
|---|---|---|
| `VAKSA-0.8.0-android.apk` — скачай, нажми «установить», разреши «из неизвестных источников» (программа твоя же, не бойся) | `VAKSA_0.8.0_x64-setup.exe` — обычный установщик. Лень ставить? Бери `gor-desktop.exe` — просто один файл, запустил и всё | `deb` — `sudo dpkg -i VAKSA_0.8.0_amd64.deb`. Не хочешь dpkg? `AppImage` — скачал, chmod +x, запустил |

Не получается установить APK? Открой сайт сервера в Chrome → меню (⋮) → **«Установить приложение»**. Это тот же мессенджер, просто ставится как сайт.

## 🚀 Первый запуск — три кнопки

1. Запусти программу → она спросит **адрес сервера** → впиши его (пример ниже ⬇️)
2. Нажми **«Создать аккаунт»** → придумай ник и пароль → всё, ты в
3. Жми **«＋» / «＋ ЧАТ»** → выбери кого добавить по нику → **пиши, кидай файлы, стикеры**

Адрес живого сервера можешь спросить у владельца (или у меня) — либо подними свой за 2 минуты ⬇️

## 🛠 Хочу СВОЙ сервер (это просто, честно)

Тебе нужна любая железка с линуксом — VPS, старый ноут, Raspberry:

```bash
# 1) Скачай и распакуй сервер из Releases (gor-linux-amd64.tar.gz)
tar -xzf gor-linux-amd64.tar.gz && cd gor

# 2) Запусти одной командой:
GOR_PORT=8080 GOR_DB=./chat.db GOR_UPLOADS=./uploads GOR_STATIC=./frontend/build ./gor
```

Готово. Сервер работает. Теперь надо чтоб наружу был виден:

- Есть домен? → прокинь nginx/caddy на порт 8080 и радуйся https.
- Лень возиться? → туннель одной строкой из коробки:

```bash
ssh -R 80:127.0.0.1:8080 nokey@localhost.run
```

Выведет адрес типа `https://random.lhr.life` — его и вписывай в клиент.

Проверка что сервер жив: открой `http://адрес:8080/api/health` → должно показать `{"status":"ok", ...}`.

Данные (сообщения, файлы) — обычные файлы рядом: `chat.db` и папка `uploads`. Бэкап = скопи-пасти папку. Всё.

- 💬 Личка и группы, непрочитанные, онлайны

- 🌙 Тёмная-тёмная тема, шрифт Roboto, иконка-губка (да, для обуви)

## 🤖 Открываешь API? Держи шпаргалку

| Метод | Путь | Что делает |
|---|---|---|
| POST | `/api/auth/register` / `/api/auth/login` | получить токен |
| GET | `/api/chats` | мои чаты |
| POST | `/api/chats` | создать `{type:"direct"…}` или `{type:"group"…}` |
| GET | `/api/chats/{id}/messages` | история (`?after=` догон, `?before=` старые, `?limit=` ≤300) |
| POST | `/api/chats/{id}/read` | отметить прочитанным |
| GET | `/api/users?q=ник` | поиск людей |
| POST | `/api/upload` | файл (multipart, ≤50 МБ) |
| GET | `/api/giphy?q=` | поиск GIF (серверу нужен `GOR_GIPHY_KEY`) |
| WS | `/ws` | живые сообщения + `presence`; токен — первым кадром |

Заголовок авторизации: `Authorization: Bearer <token>`.

## 🔨 Собрать самому из исходников

```bash
# сервер
go build -o gor .

# клиент
cd frontend && npm ci && npm run build

# виндовс/линукс приложение
cd desktop && npm ci && npx tauri build

# андроид APK (SDK/NDK — один раз поставить)
cd desktop && npx tauri android init --ci && npx tauri android build --ci --apk
```
