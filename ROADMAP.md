# VAKSA — дорожная карта

## Фаза 1 — «Мессенджер высшего уровня» (ближний спринт)
- Редактирование/удаление сообщений (типы edit/delete, UI через долгий тап)
- Реакции (emoji на сообщения, агрегация)
- Replies (ответы) — ссылка на сообщение с превью
- Typing-индикатор (WS-событие «X печатает…»)
- Доставлено/прочитано ✓✓ в реальном времени (вместо POST-only)
- Аватарки и профиль (загрузка `/api/me/avatar`, отображение в чат-листе)
- Бейдж «+3 новых сообщения» при возврате в чат
- Групповое управление: выйти, пригласить по ссылке, кик, роли админ/модератор
- Markdown-разметка (bold/italic, code, ссылки, mention) — свой безопасный рендер

## Фаза 2 — «Голос» (killer-фича уровня Discord/Telegram)
- Сигналинг через существующий WS: `call_invite / call_offer / call_answer / call_ice / call_hangup / call_busy`
- WebRTC 1:1 звонок (P2P, Opus/VP8): ringing UI, mute/speaker
- TURN (coturn) рядом с сервером — обязательный NAT traversal
- Групповые звонки через SFU (self-host LiveKit, docker-compose): комнаты как каналы, вход/выход одним тапом
- Скриншаринг (displayMedia), mute любого, переключение камеры
- Android: фоновый звонок (foreground service), рингтон/вибро (права уже в манифесте)

## Фаза 3 — «Доверие» (безопасность)
- E2E-шифрование текста (X3DH + Double Ratchet: libsodium JS / Rust в Tauri)
- E2E-ключи для медиафайлов (envelope хранит ключ)
- Web Push (VAPID) для PWA-браузеров, push для APK
- Сессии/устройства в UI: список активных устройств, отзыв сессий (в БД всё есть)
- Recovery-код / смена пароля
- Markdown XSS-аудит, CSP, токен из localStorage → secure cookies где возможно

## Фаза 4 — «Платформа»
- Карманная версия от одной БД (GOR_REALM для кланов/комьюнити): два и более инстанса на одной базе
- Каналы (группа с read-only участниками), бот-API (токен-бот, вебхуки в WS)
- Анонимные/«абстрактные» чаты (приватность уровня Telegram)
- Голосовые сообщения (MediaRecorder → opus, волна в UI)
- Поиск сообщений (FTS5) и глобальный поиск
- Мультивход: клиент на нескольких серверах сразу

## Фаза 5 — «Открытость и рост»
- Mini-apps (web-view виджеты как в ТГ) — long-term
- Стикеры: загрузка своих, прокси GIPHY
- Вход по ссылке /invite/xxx + deep-link в APK (Tauri deep-link)
- Статус-страница /status, метрики Prometheus
- Автые бэкапы (S3 / Telegram backup-bot)
